# Animations and variants

The overlay shows up when a model has several animations or material variants. It's on by default in the file view: open [[Fox.glb]] or [[MaterialsVariantsShoe.glb]] to try it.

## In embeds

Embeds hide the overlay unless you ask for it with `overlay=true`.

```markdown
![[Fox.glb#overlay=true&aspect=16:9]]
```

![[Fox.glb#overlay=true&aspect=16:9]]

```markdown
![[MaterialsVariantsShoe.glb#overlay=true&aspect=16:9]]
```

![[MaterialsVariantsShoe.glb#overlay=true&aspect=16:9]]

## Without the overlay

Choose what plays or shows with attributes instead:

```markdown
![[Fox.glb#autoplay&animation-name=Run&aspect=16:9]]
```
