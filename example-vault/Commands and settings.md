# Commands and settings

## Build an embed visually

1. Open a model, like [[DamagedHelmet.glb]].
2. Open the command palette and run **Model Viewer: Customize embed**.
3. Drag the preview to frame the model, and try out attributes.
4. Select **Copy embed** and paste it into a note.

## Set defaults

Go to **Settings → Model Viewer** and select **Edit** next to any list of attributes. You can set defaults for all models, for the file view and for embeds. More specific settings override general ones, and embed attributes override them all.

In Obsidian 1.13 and later, the settings search finds these settings as well. Searching for an attribute, such as *exposure*, shows each place where it can be set.
