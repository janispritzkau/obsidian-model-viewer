# Model Viewer examples

This vault shows what the Model Viewer plugin can do, using official glTF sample models. Every note explains a feature and shows it live, so switch to source mode to see how a page is written.

1. [[File view]]: open models in their own tab
2. [[Embeds]]: place models in your notes
3. [[Attributes]]: change how a model looks and behaves
4. [[Animations and variants]]: play animations and switch materials
5. [[Materials and lighting]]: glass, skyboxes and exposure
6. [[Compressed models]]: Draco, KTX2 and meshopt
7. [[Code blocks and annotations]]: add labels and links to a model
8. [[Commands and settings]]: build embeds visually and set defaults

The models are credited in [[Credits]].
