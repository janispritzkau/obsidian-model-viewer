# File view

Click a `.glb` or `.gltf` file in the file explorer to open it in its own tab. Try it with [[DamagedHelmet.glb]].

- **Rotate:** drag with the mouse or one finger
- **Zoom:** scroll or pinch
- **Pan:** right-click and drag, or drag with two fingers

If the Page preview core plugin is on, hover over the link above while holding `Ctrl` or `Cmd` to see the model in a popover.
