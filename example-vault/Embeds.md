# Embeds

Embed a model like any other file. It fills the width of the note:

```markdown
![[DamagedHelmet.glb]]
```

![[DamagedHelmet.glb]]

## Height

```markdown
![[Fox.glb#height=300]]
```

![[Fox.glb#height=300]]

## Aspect ratio

```markdown
![[GlassVaseFlowers.glb#aspect=16:9]]
```

![[GlassVaseFlowers.glb#aspect=16:9]]

## Width

Add a width after the pipe character, as with images:

```markdown
![[Fox.glb#aspect=1|320]]
```

![[Fox.glb#aspect=1|320]]

## Side by side

```markdown
![[DamagedHelmet.glb|200]] ![[Fox.glb|200]] ![[GlassVaseFlowers.glb|200]]
```

![[DamagedHelmet.glb|200]] ![[Fox.glb|200]] ![[GlassVaseFlowers.glb|200]]

## Scrolling on touch screens

On a phone or tablet, swipe up or down over an embed to scroll the note, and swipe sideways to rotate the model.
